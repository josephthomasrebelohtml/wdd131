Site Plan - Tony's Pizza Palace

Site Name

Tony's Pizza Palace

This site name is for a pizza restaurant created by a man named Tony.

Optional Domain Name: tonys-pizza-palace.com

Site Purpose

to facilitate Menu overview and ordering of a pizza restaurant

This site provides a hub for potential customers of Tony's Pizza Palace to learn more about the business, the menu and how to place an order.

Scenarios

to facilitate Menu overview and ordering of a pizza restaurant

  • What is the history of this restaurant that makes it trustworthy?
  • What's the food in their menu and it's ingredients?
  • What is the price of this restaurant's food?
  • How can I place an order at this restaurant?

Color Schema

Red = #B01022

This color will be used in the header, footer, pricing details and buttons

White = #FFFFFF

This color is great for the text that will be included when the background color uses a variant of Red. So, this will be for the text whenever the #B01022 is used.

Green = #005F16

This color will be for hover animations for buttons and other places to add more variety to the website.

Black = #000000

This color will be for the text that is inside white or similar background colors.

Typography

Merriweather Sans

This font will be used for most of the text in the websites; header, footers, body texts, etc.

Roboto Condensed

This font will be used for special items inside the website, like buttons, pricing, menu item names, etc.
